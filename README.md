# student-buying-behaviour-analysis

Overview

Why do students choose one product over another? Is it price, product quality, website design, convenience, or trust?

This project explores consumer buying behaviour among Indian university students using survey data from the Consumer Decision Making Data dataset. The goal is to examine shopping patterns, understand respondents’ perceptions of purchasing factors, and explore how data analytics can turn survey responses into meaningful insights.

Research Question

What factors do Indian university students consider important when making purchasing decisions?

Dataset

* Dataset: Consumer Decision Making Data
* Source: Mendeley Data
* Original dataset size: 3,329 rows and 95 variables
* Data type: Secondary survey data

The dataset was collected by the original researchers. This project analyses the existing data rather than collecting new survey responses.

Tools and Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

Methodology

1. Load and inspect the dataset.
2. Examine missing values, duplicate records, and data structure.
3. Perform exploratory data analysis (EDA).
4. Analyse selected survey variables and visualise response distributions.
5. Interpret findings while documenting limitations.

Preliminary Finding

In the supplied workbook, 83.8% of the original rows rated website design and graphics as 4 or 5 on the survey scale. This is a preliminary descriptive result, not evidence that website design causes purchases.

Data Quality and Limitations

The initial audit identified 1,695 exact duplicate rows among the 3,329 rows. The reason for these duplicates has not yet been established, so they require further investigation before final conclusions can be drawn. The dataset contains self-reported survey responses and represents a specific respondent population. Findings should therefore be interpreted within that context.
